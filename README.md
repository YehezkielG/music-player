**Music Player (GoTune)**

- **Overview**: This repository contains a music player built with a Next.js frontend (in `next/`) and an Electron wrapper (in `electron/`). The Next app is the UI and static assets provider; Electron packages the Next build and runs the desktop application.

- **Author**: Yehezkiel Haganta
- **License**: Apache License

**Quick Start**
- **Prerequisites**: Node.js (v18+ recommended) and npm installed.

- **Install and run the Next.js frontend (development)**:

```powershell
cd next
npm ci
npm run dev
```

This starts the Next dev server (Turbopack). Open http://localhost:3000 if you want to view the frontend in browser.

- **Run the Electron app (development)**:

Open a new PowerShell terminal and run:

```powershell
cd electron
npm ci
npm run start
```

`npm run start` launches the Electron app. The Electron project is configured to include the built Next output when packaging.

**Build / Production**

- Build the Next app:

```powershell
cd next
npm ci
npm run build
```

- Package Electron for Windows (single command from `electron/`):

```powershell
cd electron
npm ci
npm run dist
```

The above `dist` script runs a Next build and then `electron-builder --win`, producing artifacts in the `electron/dist` output directory per `electron/package.json` configuration.

**Repository Structure**
- `next/` — Next.js + React frontend (TypeScript). Key files:
  - `src/app/` — App routes and UI components such as `MusicPlayer.tsx`, `MusicList.tsx`, `Nav.tsx`, `Searchbar.tsx`.
  - `src/app/hooks/MusicContext.tsx` — app state for music playback.
  - `src/app/utils/` — helper utilities for folder selection and history handling.

- `electron/` — Electron main process and packaging config.
  - `main.js` — Electron entry point.
  - `preload.js` — Preload script.
  - `metadata.js` — music metadata helpers.
  - `package.json` — Electron scripts and `build` config (uses `electron-builder`).

**Development Notes**
- The Electron `build.extraResources` copies the built Next app into the packaged Electron app (see `electron/package.json` `extraResources.from` value).
- If you change the Next app and want the Electron packaged app to include changes, run the Next `build` before packaging:

```powershell
cd next
npm run build
cd ../electron
npm run dist
```

- For simple desktop testing, you can run the Next dev server and then launch Electron (Electron is configured to load local Next output in production; during dev, make sure Electron points to the dev server if you modify `main.js`).

**Scripts (from package.json)**
- `next/` scripts: `dev`, `build`, `start`, `lint`.
- `electron/` scripts: `start` (runs Electron), `build:next` (builds Next then returns to electron), `dist` (builds Next then runs `electron-builder --win`).

**Troubleshooting**
- If the Electron app fails to load the frontend, ensure the Next build exists in `next/.next` and that paths in `electron/main.js` match the built files or dev server URL.
- On Windows, run PowerShell as Administrator when `electron-builder` needs permissions to write to certain directories.
